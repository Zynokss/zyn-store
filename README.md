# ZYNSTORE — Next.js E-Commerce Platform

A sleek, modern, high-performance apparel e-commerce platform engineered with the Next.js App Router, Tailwind CSS, NextAuth, and Supabase JS over standard HTTPS REST APIs for seamless multi-tenant authentication and real-time store management.

---

## Features

- **Modern Stack:** Built on **Next.js 16 (Turbopack)**, **TypeScript**, and **Tailwind CSS**.
- **Authentication:** NextAuth JWT credentials provider backed by **Supabase JS REST API** over HTTPS (bypassing raw TCP port restrictions and connection pooling headaches).
- **Storefront UI:** Dark/Light adaptive themes, product listings, interactive cart management, and clean user profile settings.
- **Order Tracking:** Instant order status lookup via customer email or direct Order ID.
- **Fully Responsive:** Clean, mobile-first design with smooth UI/UX interactions.

---

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Database & Auth:** [Supabase JS Client](https://supabase.com/) (`@supabase/supabase-js`) & [NextAuth.js](https://next-auth.js.org/)
- **Deployment:** Docker (self-hosted via Coolify)
